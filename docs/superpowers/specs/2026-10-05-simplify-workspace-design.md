# 精简任务工作台交互

依据用户截图，保留 Orbit 苹果风格，采用侧栏、对话、看板三栏。范围是现有前端信息结构与交互入口，不改变执行器、队列、验收或持久化协议。

推荐方案：对话优先的三栏布局。中间对话占主要宽度，右侧为可折叠四列看板；紧凑屏幕切换对话与看板，避免三个区域都变窄。浅灰侧栏、白色对话、淡灰看板、系统字体、蓝色只标记选中或主操作。保留现有键盘焦点与降低动态效果支持。

侧栏将“新建任务”作为唯一新任务入口；保留工作台、归档、交付物、知识库、设置。待介入仍保留入口，场景筛选移到看板筛选，删去重复的个人工作空间卡片与常规本地保存说明；保存异常和浏览器预览限制继续显示。

任务工作台不再同时展示面包屑、大标题、描述和概览统计。对话标题栏显示任务名称、执行器与一个状态相关主操作；重新开始、归档、撤销请求、查看 Agent 和日志放进更多菜单。运行中中断、未启动启动、等待验收时验收保持直接可发现。claimed 的核对撤销必须可达，且保留后端 idle 验证。

看板卡片显示标题、执行器和必要状态；整张卡片点击选择对话，去掉重复“查看对话”以及卡片与对话两套启动/验收按钮。启动、取消和验收的按钮等价路径统一留在对话标题栏，拖动仍使用现有命令及限制。

Agent 和运行记录默认不占常驻下方空间，通过更多菜单按需打开可关闭详情区域，保留现有子 Agent 正文、同步和日志功能。交付正文在聊天里展示，打开文档继续使用既有编辑/导出窗口，避免重复交付列表。

输入框在对话底部，压缩常规说明和计数；能力限制、排队、失败信息仍明确展示。点击发送的执行语义不变，草稿随任务保留。未选择任务时显示简短入口与新建任务按钮。

替代方案：仅删除重复标题/按钮，改动较小但当前对话过窄；完全复制截图深色界面，会改变已认可的苹果风格且不是此次必要范围。

验证：前端测试、生产构建、隔离浏览器宽/窄屏检查；检查 pending、running、claimed、failed、待验收、已验收及无任务状态下主操作和菜单权限。后端不做变更，不调用真实模型、不修改用户资料。长任务完工前按 AGENTS C 复审最终 Diff；失败按规则 B 诊断。

用户追加：顶部操作参考截图，保持干净。将顶部压缩为对话/看板各自单行标题栏，不显示任务页的全局 topbar。新建集中侧栏；看板标题栏只有搜索、筛选、暂停/恢复队列、折叠看板图标，均有 accessible label 和 title。非工作台页面结构保持现有行为。
