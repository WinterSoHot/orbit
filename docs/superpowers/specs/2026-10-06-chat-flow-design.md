# Orbit 对话主流程

用户批准范围：真实消息时间线、进度、可展开工具状态、真实澄清卡片、运行中补充、停止与继续。保留 Light/Dark 苹果风格；不扩展附件、模型设置或权限。

按 (runId, threadId, itemId) 保存根 Agent 的公开消息：delta 追加、completed 的 text 权威替换；完成后拒绝迟到 delta。工具只保存类型、状态、整数退出码与白名单协作操作，绝不保存命令参数、输出、patch、URL、MCP 正文或推理文本。Qoder 保留现有可见输出兼容路径。

时间线最多 256 项、256000 Unicode 字符，单项 16000 字符；超限提示、保留已有记录、仍接受结束状态。默认 serde 字段兼容旧存储；继续保留历史、重新开始清空、恢复时进行中项变为未知。缺少稳定 ID 的事件不猜测归并。

交付仅有明确 run 关联且完整 final 与正文一致时省略重复正文，文档打开入口保留。失败/中断的有效持久化会话可继续，无需先有交付；未知、归档、队列、会话不匹配仍拒绝。澄清答复首版不持久化正文，避免秘密泄露。

对话正文自然流动、工具折叠、输入区固定；靠近底部时跟随新输出，浏览旧消息时保留滚动位置并提供返回最新。Cmd/Ctrl+Enter 发送，输入法组合期间不发送。停止复用真实执行器中断能力。
