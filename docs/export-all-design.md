# 全部工作台数据导出

用户要求：支持导出当前所有的数据。

设置页“导出全部数据”将当前 Store 的一致快照导出为 UTF-8 JSON，沿用已配置的导出文件夹。包含全部任务（包括归档和运行中）、Agent 详情、活动记录、待处理请求记录、补充方向/对话、全部交付版本正文、会话引用、能力和导出设置。直接序列化完整 Workspace，外加 format=orbit-workspace、version=1、exportedAt（UTC Unix 毫秒），不手工选择任务字段。

运行中导出是点击后取得快照时的状态。未保存的编辑和聊天草稿不属于快照；等待已提交的文档保存，失败阻止导出，明确丢弃草稿后可导出已保存版本。没有自动保存或防抖队列。导出仅复制数据，不改变任务、审批或执行器状态；不调用模型。外部 CLI 会话数据库、登录凭据和工作目录文件不属于工作台记录，此功能不扫描它们，也不提供导入/续跑。

健康空工作空间可以导出；Store 已识别的加载错误不能导出为空。读取当前权威 Store，而非 UI 筛选列表或重新打开磁盘文件；加载后的外部文件篡改不新增监听。导出时在 Store 锁内一起取得完整快照和时间戳，再释放锁进行序列化和文件 IO。保存事务先 persist 再提交内存。

文件名使用时间戳与 UUID，create_new 防覆盖；权限 0600（Unix），完整写入并 sync_all 后返回。写入失败时尝试清理本次创建的文件，原记录保持不变。检查时目录失效/重定向报错，不回退。复用单份交付的目录与写入路径，无新依赖。

候选方案与最终 Diff 已通过只读 architect 审查（规则 A / C）。

最终审查保留两项现有写入边界：目录校验后按路径打开文件，不能阻止校验与打开之间的并发目录替换；失败清理为尽力处理，删除失败时可能留下不完整文件。本轮未增加目录 FD 绑定或清理重试机制。
